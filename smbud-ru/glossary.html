cache (кэш)

"Data duplicating original values stored elsewhere or computed earlier" (p. 367). Запрос, который находит свой ключ, — попадание (hit), который не находит — промах (miss); hit ratio — доля попаданий среди всех запросов. Кэш окупается, когда hit ratio больше отношения стоимости обращения к кэшу к стоимости обращения к оригиналу, \(h \gt t_c / t_o\): слайдовое "more cache hits then cache misses" (p. 371), то есть \(h \gt 0.5\), — лишь частный случай, когда обращение к кэшу стоит половину похода к оригиналу. CAP theorem (теорема CAP) Brewer's theorem

Из согласованности (consistency), доступности (availability) и устойчивости к разделению (partition tolerance) распределённая система не может гарантировать все три. Слайдовое "A distributed system can satisfy any two of these guarantees at the same time but not all three" (p. 195) вводит в заблуждение, и следующий слайд это поправляет (p. 196): разделения сети неизбежны, поэтому, пока разделение длится, система выбирает согласованность (CP: отвечает правильно или ошибкой) или доступность (AP: отвечает, возможно, устаревшими данными); "CA" имеет смысл только на одной площадке (single site).

combiner

Необязательный мини-reduce, который выполняется над выходом каждой map-задачи до shuffle, чтобы по сети шли только частичные результаты: подсчёт слов отправляет ⟨store, 4⟩ вместо четырёх ⟨store, 1⟩. cosine similarity (косинусное сходство)

Косинус угла между двумя векторами, \(\cos\theta = A \cdot B \,/\, (\lVert A\rVert\,\lVert B\rVert)\): 1, когда они смотрят в одну сторону, 0 — когда ортогональны, −1 — когда противоположны. Скалярное произведение (inner product) \(A \cdot B\) — это только числитель, поэтому оно растёт с длинами векторов; евклидово расстояние измеряет зазор между их концами. Для единичных векторов все три меры ранжируют одинаково, поскольку \(\lVert A - B\rVert^2 = 2 - 2\cos\theta\). Сходство наибольшее для лучшего совпадения, а косинусное расстояние \(1 - \cos\theta\) — наименьшее.

query operator

Фильтр в MongoDB сам является документом, а любое условие, кроме равенства, — оператор со знаком доллара: {"price": {"$gt": 100}}. ZooKeeper

Сервис координации для распределённых систем: клиенты HBase спрашивают у него, какой HRegionServer обслуживает их строки, Resource Manager из YARN сохраняет в нём своё состояние, а Nimbus и Supervisors в Storm общаются только через него и хранят там своё состояние.
