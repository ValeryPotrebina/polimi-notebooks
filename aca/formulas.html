Formula sheet

The cheat boxes of 38 lessons on one page: 360 rows of formulas and rules, each a name and what you would write next to it.

Every box below is the cheat box from the "Key take-aways" of one lesson, copied here unchanged. A row is a name and a formula — CPI, speedup, AMAT, miss rate, code efficiency — or a name and a rule: when an instruction may issue in Tomasulo’s machine, what a cache does on a read miss, how the home directory answers a request. The heading above a box leads to the lesson that explains it with worked examples.

At the exam you may bring one A4 page, front side only, with formulas in 12-point type or larger and no copies of past exercises or slides (the rules are in the exam trainer). The 360 rows here will not fit on one side at that size, so this page is where you choose what goes on yours.

Revise with it like this. Read a name, cover what follows it, write the formula or the rule from memory, then compare. What you rebuild without effort can stay off your A4; what you get wrong twice goes on it. When a row does not match, open the lesson and redo its worked example.

Lesson 1 · The assembly line in silicon

Sequential time
\(T_{\text{seq}} = n\,k\,T\) — \(n\) instructions, \(k\) stages, \(T\) = stage time
Pipelined time
\(T_{\text{pipe}} = (k + n - 1)\,T\); cycles = IC + (k − 1) = IC + 4 for five stages (no stalls)
Speedup
\(S(n) = \dfrac{n\,k}{k + n - 1} \to k\) for \(n \to \infty\)
Clock period
\(T_{\text{clk}} \ge \max_i d_i + t_{\text{reg}}\) — slowest stage delay \(d_i\) plus register overhead; ceiling = \(T_{\text{instr}} / T_{\text{clk}}\)
Stages and resources
IF: I-memory, PC + 4 · ID: register read (2 ports) · EX: ALU · MEM: D-memory · WB: register write (1 port)
Where a value is born
ALU result: end of EX · loaded word: end of MEM · PC of a taken branch: MEM (basic pipeline)
Pipeline registers
IF/ID: instruction, PC + 4 · ID/EX: PC + 4, rs1, rs2, imm, rd, control EX/MEM/WB · EX/MEM: ALU result or address, store data, target, rd, control MEM/WB · MEM/WB: memory data or ALU result, rd, control WB
Rule
no stage is skipped: idle stages are traversed, latency is always 5 cycles

Lesson 2 · When the line jams: hazards and forwarding

Stalls without forwarding
\(\max(0,\ 3 - d)\), \(d\) = distance producer → consumer; without the split-cycle register file \(\max(0,\ 4 - d)\)
Stalls with forwarding
ALU producer: 0 at any distance; load → operand or address: \(\max(0,\ 2 - d)\) (1 at \(d = 1\)); load → store data: 0 (MEM/MEM)
Paths
EX/EX: EX/MEM → ALU input · MEM/EX: MEM/WB → ALU input · MEM/MEM: MEM/WB → data-memory write input
Forwarding unit
forward from EX/MEM if EX/MEM.RegWrite, EX/MEM.rd ≠ R0, EX/MEM.rd = ID/EX.rs; else from MEM/WB under the same test; newest wins
Hazard detection
stall if ID/EX.MemRead and ID/EX.rd = IF/ID.rs1 or rs2 (a store's data register exempt: MEM/MEM serves it): hold PC and IF/ID, zero the controls into ID/EX
Clock cycles
\(\text{cycles} = IC + 4 + \text{stalls}\) = cycle of the last WB; \(\text{CPI} = \text{cycles} / IC\)
Slots to insert
nops or independent instructions needed = stalls the hardware would insert

Lesson 3 · What “faster” means: the Iron Law, Amdahl and pipeline arithmetic

Performance
\(1 / \text{Execution time}\)
X is n% faster than Y
\(\text{Time}(Y) = (1 + \tfrac{n}{100})\,\text{Time}(X)\)
Clock
\(f_{CLK} = 1/T_{CLK}\); 500 MHz = 2 ns, 200 MHz = 5 ns, 1 GHz = 1 ns
CPU time
\(IC \times CPI \times T_{CLK}\), or \(IC \times CPI / f_{CLK}\)
Weighted CPI
\(\sum_i CPI_i\, F_i\), with \(F_i = I_i / IC\) the frequency of class \(i\)
IPC
\(1 / CPI\)
MIPS
\(f_{CLK} / (CPI \times 10^6)\), or \(IC / (\text{time} \times 10^6)\)
Amdahl
\(\text{Speedup} = 1 / \big((1 - F) + F/S\big)\); \(\text{Speedup}_{\max} = 1/(1 - F)\); \(F = (1 - 1/\text{Speedup}) / (1 - 1/S)\)
5-stage pipeline cycles
\(IC + \text{Stall cycles} + 4\); \(CPI = \text{cycles} / IC\)
Loop, one iteration
\(\text{cycles} = m + k + 4\); \(CPI_{iter} = (m + k + 4)/m\) (\(m\) instructions, \(k\) stalls per iteration)
Loop, n iterations
\(\text{cycles} = n(m + k) + 4\); \(CPI_{AS} = (m + k)/m = 1 + k/m\); \(\text{MIPS}_{AS} = f_{CLK}/(CPI_{AS} \times 10^6)\)
Ideal and realistic CPI
ideal 1 for single issue (\(1/w\) for \(w\)-issue); realistic \(1 + \text{stall cycles per instruction}\)
Pipeline speedup
avg exec time unpipelined / pipelined = \(CPI_{unp}/CPI_{pipe}\) = depth / (1 + stall cycles per instruction); branches only: \(\text{depth}/(1 + b\,p)\)

Lesson 4 · Why the pipeline hates branches: static prediction and the delay slot

Branch penalty
\(r - 1\) cycles, \(r\) = stage at whose end the PC is written (ID: 1, EX: 2, ME: 3)
CPI with branches
\(\text{CPI} = 1 + f_b \cdot \text{penalty} \cdot p_{\text{mis}}\); \(f_b\) = branch fraction
Misprediction probability
stall: 1; always NT: \(p_T\); always T (BTB hit): \(1 - p_T\); BTFNT: \(p_T\) of forward branches, \(1 - p_T\) of backward ones
Loop of N iterations, branch at the bottom
always NT: \(N - 1\) mispredictions; always T and BTFNT: 1 (the exit)
Exit test at the top, N iterations
executed \(N + 1\) times: always NT 1 miss, always T \(N\)
Cycles of a program
\(\text{IC} + 4 + \text{stalls}\); per iteration \(m + k + 4\), \(\text{CPI}_\infty = (m + k)/m\)
Delay slot
always executed; from before: no condition; from target: harmless if not taken, copy at the label; from fall-through: harmless if taken; NOP = stall
Exam convention
branch solved in ID, ALU → branch latency 2, one counted delay slot "(delay slot)", no prediction

Lesson 5 · Learning from the past: 1-bit and 2-bit history tables, and the BTB

CPI with branches
\(\text{CPI} = \text{CPI}_{\text{ideal}} + f_b (1 - a) P\) — \(f_b\) branch fraction, \(a\) accuracy, \(P\) penalty (1 here)
Misprediction rate
\(r = \dfrac{\text{mispredictions}}{\text{executions of the branch}}\), warm-up included; \(a = 1 - r\)
Executions of a loop branch
bottom-tested (BNE at the end): \(N\); top-tested (BEQ exit at the top): \(N + 1\)
1-bit on a loop of \(N\), re-run
2 misses (exit + re-entry): accuracy \((N - 2) / N\)
2-bit on the same loop
1 miss (exit): \((N - 1) / N\); from SNT add 2 warm-up misses, from WNT add 1
2-bit rule
strong state: one anomaly moves to the weak state, prediction unchanged; weak state: one anomaly flips the prediction
BHT size
\(2^k\) entries \(\times\) \(n\) bits, no tags
BTB entry
tag + predicted target address (+ T/NT bits); only taken branches, written at resolution
BTB cases
predict NT → PC + 4; predict T and hit → PTA, 0 cycles if taken; predict T and miss → PC + 4, then BTA in ID, 1 cycle if taken
Penalty per branch with a BTB
\(p_{hit}(1 - p_{ok})P + (1 - p_{hit})\,p_{taken}P\)

Lesson 6 · Branches that talk to each other: correlating and two-level predictors

(m, n) predictor
\(2^m\) tables (m history bits) × \(2^k\) entries (k PC bits) × n bits; storage \(2^m \cdot n \cdot 2^k\) bits; the plain 2-bit BHT is (0, 2)
Single-table index
\(\text{GHR} \,\Vert\, \text{PC}[k]\): m + k bits, GHR on top
GHR update
shift left, insert 1 (Taken) or 0 (Not Taken) on the right, keep m bits — notes: 01 = last T, penultimate NT
gshare index
\(\text{BHR} \oplus \text{PC}[h]\), h bits each, \(2^h\) entries
Local two-level size
\(2^k h + 2^{h+1}\) bits: \(2^k\) histories of h bits plus one PHT of \(2^h\) 2-bit counters
Loop exit learnable
local history \(h \ge N - 1\) (N iterations, N − 1 taken then not taken)
Misses per loop pass, steady state
1-bit: 2 (exit + re-entry) · 2-bit and always Taken: 1 (exit) · two-level with h ≥ N − 1: 0
Branch executions
bottom-tested loop: N · top-tested loop: N + 1 (the exit test)
CPI with branches
\(\text{CPI}_{\text{ideal}} + f_b (1 - a) P\): branch frequency × misprediction rate × penalty

Lesson 7 · Three ways instructions collide, and pipelines where EX takes more than a cycle

Dependence table (EX1)
true: nearest earlier writer of each source register · anti: every earlier reader of the destination · output: every earlier writer of the destination · SD, BNE: true only · intra-loop only
Two properties to preserve
data flow (each consumer gets the value program order designates) · exception behaviour (same exceptions, no new ones)
Renaming removes
WAR and WAW (names); never RAW (a value), never control
When a hazard is possible
RAW: always · WAR: never in the 5-stage pipeline (reads in ID, in order); with delayed operand reads (scoreboard) · WAW: once writes complete out of order (different latencies), even with in-order issue
RAW cost, back to back
unit of \(n\) execution cycles, forwarding at the end: \(n - 1\) stalls (ALU 0, load 1, 3-cycle adder 2); H&P call these stalls the "latency"
Latency / initiation interval
cycles to the result / cycles between two issues to the same unit (1 if fully pipelined, the execution time if not)
Exam latency
"LD latency 4": issue 1, start exec 2, write result 6; a consumer starts at write result + 1
Precise exception
all older instructions completed, no younger one has changed the state; restart at the faulting instruction · 5-stage pipeline: taken at WB, oldest first
Dynamic scheduling
issue in order · execute and write result out of order · commit in order (reorder buffer)
Loop-carried dependence
from an instruction of iteration \(i\) to one of iteration \(i + k\) (through a register like R1, or an array element written in an earlier iteration)

Lesson 8 · Doing more per cycle: superscalar, static vs dynamic scheduling, the limits of ILP

Ideal CPI, IPC
\(\mathrm{CPI}_{ideal} = 1/w\), \(\mathrm{IPC}_{ideal} = w\) (\(w\) = issue width)
Instructions in flight
\(w \times \text{depth}\)
Real CPI
\(\mathrm{CPI}_{ideal} + \text{stalls/instr}\)
CPI with branches
\(\mathrm{CPI}_{ideal} + f_b\, m\, P\) (\(f_b\) branch frequency, \(m\) misprediction rate, \(P\) penalty)
SMT per-thread CPI
\(\text{threads}/w\); core CPI \(1/w\)
Code efficiency
\(\mathrm{IC}/(\#\text{cycles} \times \#\text{issues})\)
Amdahl (notes)
\(1/\big(f + (1-f)/p\big)\), ceiling \(1/f\) (\(f\) serial fraction, \(p\) speedup of the rest)
Amdahl (formula sheet)
\(1/\big((1-F) + F/S\big)\), ceiling \(1/(1-F)\) (\(F\) enhanced fraction, \(S\) its speedup)
The ladder rule
issue and commit in order; only execution out of order; the width grows

Lesson 9 · The chalkboard that beat the pipeline: the scoreboard

Issue (in order)
unit not Busy and Result[D] empty; \(I_n\) = max of \(I_{n-1}+1\), \(WB_U+1\), \(WB_W+1\) — \(U\) previous instruction on the unit, \(W\) pending earlier writer of \(D\)
Read Operands
\(R_j = R_k = \text{Yes}\); \(RR_n = \max(I_n+1,\ WB_P+1)\) — \(P\) producer of each source (no forwarding)
Execute
\(E_n = RR_n + L\), \(L\) latency of the unit; Time counts down from \(L\)
Write Result
no row with \(F_j\) or \(F_k = D\) and flag Yes; \(WB_n = \max(E_n+1,\ RR_A+1)\) — \(A\) earlier readers of \(D\)
Rj, Rk
source ready and not yet read: Yes when the producer writes, No at the read
Qj, Qk
the unit that will produce Fj, Fk; copied from Result[S] at issue
Unit Busy
from I through WB inclusive; free for a new issue at WB + 1
CPI
\(\text{CPI} = \dfrac{\text{last } WB}{IC}\) — cycle of the last write result over the instruction count

Lesson 10 · 62 cycles, one at a time: the scoreboard example and the exam table

Basic scheme (WAW at Issue, no forwarding)
\(I_n\) = max of \(I_{n-1}+1\), \(WB_U+1\), \(WB_W+1\); \(RR_n = \max(I_n+1,\ WB_P+1)\); \(E_n = RR_n + L\); \(WB_n = \max(E_n+1,\ RR_A+1)\) — \(U\) previous instruction on the unit, \(W\) pending earlier writer of the destination, \(P\) producer of each source, \(A\) earlier readers of the destination
Forwarding
\(RR_n = \max(I_n+1,\ WB_P)\): the consumer reads in the producer's write cycle
WAW check at write-back
drop \(WB_W+1\) from \(I_n\); add \(WB_n \ge WB_W+1\) at Write Result (the WAR test stays)
Unit Busy
from I through WB inclusive; a new issue on it at WB + 1; the first free unit of the class is taken
Rj, Rk
ready and not yet read: Yes when the producer writes, No at the read — the WAR test looks for a Yes
CPI
\(\text{CPI} = \dfrac{\text{last } WB}{IC}\): 62/6 ≈ 10.3; 25/7 ≈ 3.57; 21/7 = 3.0
Speedup
\(\dfrac{\text{cycles}_{\text{basic}}}{\text{cycles}_{\text{opt}}}\) = 25/21 ≈ 1.19 (same IC, same clock)
Critical chain
the longest RAW chain plus its structural waits: LD F2 → FMUL → FDIV = 8 + 1 + 10 + 1 + 1 + 40 + 1 = 62

Lesson 11 · Names, not values: Tomasulo’s architecture

Reservation station
Busy · Op · Vj, Vk (operand values) · Qj, Qk (producer tags, 0 = ready) · A (load/store: immediate, then effective address)
Register status
Qi = tag of the newest pending writer of the register; Qi = 0 → use Vi
Issue
free station of the right type → copy values or tags from the register file; Qi[dest] ← this station
Execute
Qj = Qk = 0 (both operands as values) and the unit is free → compute for the latency
Write result
CDB free → broadcast <tag, value>; every Qj/Qk = tag fills; register written only if Qi = tag; station freed
Store
waits for address and data (either may be a tag) → writes memory; never uses the CDB
CDB capacity
one result per bus per cycle; in the exam the older instruction writes first
Scoreboard vs Tomasulo
stalls on WAR / WAW vs renames; data through the register file vs broadcast with a tag; central vs distributed control; waits for a register vs for a value or tag

Lesson 12 · Issue, execute, write result: the three stages and the exam table

Issue (in order)
free RS of the class; \(I_n = \max(I_{n-1} + 1,\ W_{\text{RS}} + 1)\) — \(W_{\text{RS}}\) the WRITE RESULT that first frees a station of the class (if none is free at \(I_{n-1} + 1\)); Vj/Vk ← value if Qi = 0 else Qj/Qk ← Qi; Qi[dest] ← this RS
Start exec
\(Q_j = Q_k = 0\) and unit free; \(S_n\) = the latest of \(I_n + 1\), \(W_P + 1\), \(W_U + 1\) — \(P\) each producer, \(U\) the unit's last occupant
Write result
\(W_n = S_n + L\), \(L\) the latency; one CDB per cycle, oldest first, the younger slips by one
Broadcast
⟨tag, value⟩: every RS with Qj or Qk = tag fills; the register is written only if Qi = tag; the RS and the unit are freed
Store
starts when address and data are ready; \(W = S + L\) = end of the memory write; no CDB broadcast, no CDB slot
Hazards column
RAW with I# for F; WAR / WAW with I# "solved by renaming" (optional); Structural (RS, unit, CDB); "issue delayed behind I#" for a row held up by in-order issue
Dependences
true: nearest earlier writer of a source; anti: every earlier reader of the destination; output: every earlier writer of the destination
CPI
\(\text{CPI} = \dfrac{\text{last WRITE RESULT}}{IC}\) — the last write cycle over the instructions of one iteration

Lesson 13 · Tomasulo cycle by cycle, and what it fixes compared with the scoreboard

Start of execution
\(S = \max(I + 1,\ W_{\text{prod}} + 1,\ U)\) — \(I\) issue, \(W_{\text{prod}}\) write of each pending producer, \(U\) first cycle the unit is free (busy through the write cycle of its instruction)
Write result
\(W = S + L\), \(L\) the latency; execution occupies \(S \dots S + L - 1\)
Single CDB
one write per cycle; two ready → the older writes, the younger slips by one ("Structural on the CDB")
Register-file rule
a broadcast ⟨tag, value⟩ is written into F only if Qi[F] = tag; a station copies it into Vj / Vk if Qj / Qk = tag
Issue rule
in order, one per cycle, only into a free station; a station is busy from issue through write result; no station free → "Structural", everything behind waits
Stores
issue to a LOAD/STORE station; write result = end of the memory write; never on the CDB
CPI
\(\text{CPI} = W_{\text{last}} / N\) (last WRITE RESULT over the instructions of one iteration)
The classic run
load 2, add 2, mult 10, div 40: one load unit 1-2-4 · 2-5-7 · 3-8-18 · 4-8-10 · 5-19-59 · 6-11-13 (CPI 59/6); two load units: LD F2 2-3-5, finish 57; scoreboard: 62 cycles, all issued at 13, FADD written at 22
What vanishes, what stays
WAR / WAW → "solved by renaming"; issue stalls on busy units → waits in stations; RAW → still waits (producer's write + 1); the critical chain → unchanged

Lesson 14 · Tomasulo under pressure: structural squeezes and CDB fights

Issue
in order, one per cycle, needs a free RS of the class; RS busy from ISSUE through WRITE RESULT inclusive, reusable the next cycle
Start Exec
the latest of ISSUE + 1, the producer's WRITE RESULT + 1, and the cycle after the unit's previous WRITE RESULT (a unit is busy through the WRITE RESULT of its instruction)
Write Result
\(\text{START EXEC} + \text{latency}\), +1 per older result taking the single CDB in that cycle (oldest first); a store's write is its memory write
Tag
Qj / Qk = the RS of the producer; the CDB carries \(\langle \text{tag}, \text{value} \rangle\); readers copy values at issue, so WAR and WAW never stall
CPI
\(\dfrac{\text{last WRITE RESULT}}{\text{IC}}\): 22/8 = 2.75 (Feb 2025), 22/10 = 2.2 (midterm 2025), 22/8 = 2.75 (June 2025)
Hazards column
None · Structural (RSx, RSy busy, cycles a–b) · Structural (FPU1 busy until c) · Structural (CDB at c: I# first) · RAW with I# (Fx) · WAR/WAW with I# (Fx): renamed

Lesson 15 · Same names, no conflicts: unrolling, renaming and scheduling

Trip count
N = distance the index travels / step (R1: 0 → 400 by 4: N = 100; 80 → 0 by 8: N = 10)
Unrolled by u
\(N/u\) iterations of \(u\,w + o\) instructions, \(N/u\) branches (w useful, o overhead instructions per original iteration); if u does not divide N: N mod u remainder iterations of the original body
Instructions executed
\(IC_u = N w + N o / u\)
Saving
\(\dfrac{o\,(1 - 1/u)}{w + o}\), limit \(\dfrac{o}{w + o}\) (midterm loop: 21.43 %, 32.14 %, limit 42.9 %)
Extra registers (static renaming)
\((u - 1)\,\rho\), ρ = registers one copy writes (midterm: F2, F4, F6, ρ = 3; section 1: F0, F4, ρ = 2 — a register that is only read, like the scalar F2 there, is not renamed)
Overhead per element
\(o / u\) (3 → 1.5 → 0.75)
Displacement below the index update
new = old − ΔR1 (ΔR1 = −32: −24 → +8, −16 → +16)
H&P latencies (stall cycles)
LD → FP op 1 · LD → SD 0 · FP op → FP op 3 · FP op → SD 2 · SUBI → BNE 1
Loop on a pipeline
m instructions + k stalls per iteration: \(CPI_{AS} = (m + k)/m\); cycles per element = (m + k)/u — 9 original, 7 scheduled, 6.75 unrolled, 3.5 unrolled + renamed + scheduled
Schedule order
loads first, FP operations next, stores last; at least one instruction between the index update and the branch
Table 20
Tomasulo: renaming yes (tags), scheduling yes (operand availability), unrolling no — it overlaps iterations

Lesson 16 · Tomasulo meets a loop: eighteen cycles of renaming in action

Issue
in program order, one per cycle, into a free station or buffer of the class; a missing operand becomes a tag (Qj, Qk, a store's FU), never a stall; no free station → the instruction and all behind it wait (Structural)
Start of execution
\(S = \max(I + 1,\ W_{\text{prod}} + 1,\ U)\) — \(I\) issue, \(W_{\text{prod}}\) write cycle of the last producer, \(U\) first cycle the unit is free
Write result
papers: \(W = S + L\), \(L\) the latency; notes: Exec Comp = \(S + L - 1\), Write Res = Exec Comp + 1; one cycle later for every older result that takes the CDB first
CDB capture
one ⟨tag, value⟩ per cycle, oldest first; every entry whose Qj, Qk or FU equals the tag copies the value
Register write
F ← value only if F's status equals the tag (its youngest writer); otherwise the broadcast is ignored
Station lifetime
busy from ISSUE through WRITE RESULT; papers: free the next cycle; the notes refill it in the same cycle
Store
START EXEC = data's WRITE RESULT + 1; papers: WRITE RESULT = START EXEC + LDU latency, no CDB slot; notes: memory written the cycle after execution
Time field
execution cycles still to run after the current one (4, 3, 2, 1, 0 for FMUL)
CPI (papers)
\(\text{CPI} = W_{\text{last}} / N\): last WRITE RESULT over the instructions of one iteration; this loop: 15 / 5 = 3.0

Lesson 17 · Guess now, pay later: speculation, precise exceptions and the reorder buffer

Commit condition
at the head AND Ready = Yes AND Spec = No → write the register (or memory for a store), free the entry, head ← head + 1 (mod N)
Issue
needs a free reservation station of the right class AND a free ROB entry; the entry is the tail, tail ← tail + 1 (mod N); the destination register is mapped to this ROB#; Spec = Yes if an older branch is unresolved
Operand at issue
no mapping → value from the register file; mapped and ready → value from ROB[h]; mapped and not ready → tag h, wait for the CDB (the "RAW with I#" of the table)
Write Result
CDB carries (ROB#, value) to the waiting stations and to the entry: Ready = Yes; the station is freed; the register file is not touched
Full / empty
head = tail and busy → full, issue stalls; head = tail and not busy → empty
Misprediction
free every entry younger than the branch; tail ← branch + 1; rename table back to the older in-flight producer or "–"; fetch restarts; the branch commits normally; nothing to undo in the registers
Precise exception
stop at one instruction, all older ones committed, no younger one has changed the state; recorded in the entry, taken at the head; on a flushed path, discarded
Exam columns
