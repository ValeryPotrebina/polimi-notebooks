Шпаргалка формул

Формулы 27 уроков на одной странице: 269 строк «название — формула» из шпаргалок, которыми заканчивается каждый урок.

Каждая рамка ниже — шпаргалка из раздела «Унести с собой» одного урока, перенесённая сюда без изменений: у каждой строки есть название и формула. Заголовок над рамкой ведёт в урок, где эта формула выведена и показана на рисунке или в виджете.

Взять этот лист на экзамен нельзя: записи и материалы курса там запрещены (правила собраны в экзаменационном тренажёре). Поэтому лист служит для повторения. Закрой формулы ладонью или листом бумаги, прочитай название, запиши формулу по памяти и сверь. Не сошлось — открой урок и пройди вывод ещё раз.

Обозначения едины для всего курса и совпадают со слайдами: векторы набраны обычным шрифтом, \(\vb{w}\T\vb{x}\) — скалярное произведение, дробная часть отделена точкой. На телефоне длинная формула прокручивается вбок внутри своей строки.

Урок 1 · Что значит «машина учится»

Expected risk
\(R(\vb{w}) = \E_{p_{\mathrm{data}}}[L(g(x|\vb{w}), t)]\)
Empirical risk
\(\hat R_N(\vb{w}) = \frac{1}{N}\sum_n L(g(x_n|\vb{w}), t_n)\)
Generalization gap
\(R(\hat{\vb{w}}) - \hat R_N(\hat{\vb{w}})\), где \(\hat{\vb{w}} = \argmin_{\vb{w}} \hat R_N(\vb{w})\)
SSE (слайды)
\(E(\vb{w}) = \sum_n (t_n - g(x_n|\vb{w}))^2\)
Accuracy
\(\frac{\mathrm{TP} + \mathrm{TN}}{\mathrm{TP} + \mathrm{FP} + \mathrm{FN} + \mathrm{TN}}\)
Precision, recall
\(\frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FP}}\), \(\frac{\mathrm{TP}}{\mathrm{TP} + \mathrm{FN}}\)
F1
\(\frac{2\,\mathrm{TP}}{2\,\mathrm{TP} + \mathrm{FP} + \mathrm{FN}}\)
MSE, MAE
\(\frac{1}{N}\sum_n (t_n - g_n)^2\), \(\frac{1}{N}\sum_n |t_n - g_n|\), где \(g_n = g(x_n|\vb{w})\)
\(R^2\)
\(1 - \frac{\sum_n (t_n - g_n)^2}{\sum_n (t_n - \bar t\,)^2}\)
Classification
\(g : \mathcal{X} \to \{1, \dots, K\}\)
Regression
\(g : \mathcal{X} \to \R\)

Урок 14 · Жалоба идёт назад по конвейеру

Урок 20 · Когда нажать «стоп»

Четыре шага (лекция 3, слайд 12)
hold out → train → cross-validation on the hold out set → stop when validation error increases
Цель остановки
\(k_{ES} = \argmin_k E_{\mathrm{val}}(k)\)
Ошибка в точке остановки
\(E_{ES} = E_{\mathrm{val}}(k_{ES})\); на слайде \(E_{ES}(x \mid w)\)
Рекорд
\(E_{\mathrm{best}}(k) = \min_{j \le k} E_{\mathrm{val}}(j)\)
Улучшение
\(E_{\mathrm{val}}(k) \lt E_{\mathrm{best}}(k-1)\)
Стоп
первая эпоха с \(k - k_{\mathrm{best}} \ge P\)
Что вернуть
\(\vb{w}^{k_{\mathrm{best}}}\), не веса последней эпохи
Цена patience
\(P\) эпох после рекорда
После \(\tau\) шагов
\(w^{\tau} = [1 - (1 - \eta\lambda)^{\tau}]\,w^{*}\)
Связь с weight decay
\(\gamma \approx 1 / (\eta\,\tau)\) при штрафе \(\tfrac{\gamma}{2} w^2\); при \(\gamma w^2\), как на слайде 15 лекции 3, \(\gamma \approx 1 / (2\eta\,\tau)\)

Урок 22 · Пружины на весах

Error function
\(E = E_{\mathrm{train}} + \gamma \sum_{q=1}^{Q} w_q^2\): Fitting + Regularization
То же в конспекте
\(E_{\mathrm{train}} + \frac{\gamma}{2} \sum_q w_q^2\)
Усадка за шаг
\(1 - 2\eta\gamma\) (в конспекте \(1 - \eta\gamma\))
MAP
\(\argmax_{\vb{w}} P(D|\vb{w})\,P(\vb{w})\)
Prior
\(w_q \sim N(0, \sigma_w^2)\)
Смысл γ
\(\gamma = \sigma^2 / \sigma_w^2\)
Один вес
\(w_{\mathrm{MAP}} = \frac{N}{N + \gamma}\, w_{\mathrm{MLE}}\)
Сжатие направления
\(\lambda_i / (\lambda_i + \gamma)\)
Выбор γ
\(\gamma^* = \argmin_\gamma\, E_{\gamma}^{\mathrm{VAL}}\); штраф есть в \(E_{\gamma}^{\mathrm{TRAIN}}\), в \(E_{\gamma}^{\mathrm{VAL}}\) его нет
L1
\(\gamma \sum_q \abs{w_q}\), Laplace prior

Урок 23 · Тренировка с отсутствующими

Маска
\(m_j \sim Be(p)\), \(p\) — keep probability
Drop rate
\(1 - p\); в тексте слайда 17 лекции 3 это \(p_j^{(l)}\)
Обучение, классический
\(\tilde h_j = m_j\, h_j\)
То же на слайде 17 лекции 3
\(h^{(l)}\big(W^{(l)} h^{(l-1)} \odot m^{(l)}\big)\)
Тест, weight scaling
\(h_j^{\mathrm{test}} = p\, h_j\)
Обучение, inverted
\(\tilde h_j = m_j\, h_j / p\)
Тест, inverted
\(h_j^{\mathrm{test}} = h_j\)
Среднее
\(\E[\tilde h_j] = p\, h_j\)
Дисперсия
\(\mathrm{Var}[\tilde h_j] = p(1 - p)\, h_j^2\)
Число подсетей
\(2^n\)
Вероятность маски
\(p^{\,k} (1 - p)^{\,n - k}\)

Урок 24 · Испорченный телефон

Передача назад
\(\delta_i^{(l-1)} = g'(a_i^{(l-1)}) \sum_j w_{ji}^{(l)} \delta_j^{(l)}\)
Цепочка
\(\delta^{(1)} = \delta^{(L)} \prod_{l=2}^{L} w^{(l)} g'(a^{(l-1)})\)
sigmoid
\(g' = g(1 - g) \le 0.25\)
tanh
\(g' = 1 - g^2 \le 1\)
ReLU
\(\max(0, a)\); \(g' = 1_{a \gt 0}\): 1 при \(a \gt 0\), иначе \(0\)
Leaky ReLU
\(\alpha a\) при \(a \le 0\); \(g' = \alpha\) (на слайде 28 лекции 3 \(\alpha = 0.01\))
ELU
\(\alpha(e^{a} - 1)\) при \(a \le 0\); \(g' = \alpha e^{a}\)
SELU
\(\lambda \cdot \mathrm{ELU}(a)\), \(\lambda \approx 1.0507\), \(\alpha \approx 1.6733\)
Softplus
\(\ln(1 + e^{a})\); её производная — sigmoid \(\sigma(a)\)
Swish
\(a \cdot \sigma(a)\); E-swish: \(\beta \cdot a \cdot \sigma(a)\)
Clipping
\(\nabla E \leftarrow \nabla E \cdot \min(1,\ c / \norm{\nabla E})\)

Урок 25 · Ксерокопия ксерокопии

Линейный нейрон, слайд 31 лекции 3
\(\mathrm{Var}(h_j) = I\,\mathrm{Var}(w)\,\mathrm{Var}(x)\)
Запись на слайдах
\(N(0,\ \sigma^2)\): второй аргумент — дисперсия
Усиление слоя, forward
\(n_{in}\,\mathrm{Var}(w)\,\E[h^2]/\mathrm{Var}(z)\)
Усиление слоя, backward
\(n_{out}\,\mathrm{Var}(w)\,\E[g'^2]\)
Xavier, только forward (слайд 32 лекции 3, (69))
\(\mathrm{Var}(w) = 1/n_{in}\)
Xavier / Glorot (слайд 32 лекции 3, (71))
\(\mathrm{Var}(w) = \dfrac{2}{n_{in} + n_{out}}\)
Xavier uniform (вне слайдов)
\(a = \sqrt{6/(n_{in} + n_{out})}\)
He / Kaiming (слайд 32 лекции 3, (72))
\(\mathrm{Var}(w) = \dfrac{2}{n_{in}}\)
He uniform (вне слайдов)
\(a = \sqrt{6/n_{in}}\)
Uniform \(U(-a, a)\)
\(\mathrm{Var} = a^2/3\)
ReLU, \(z\) симметрично
\(\E[h^2] = \tfrac12\mathrm{Var}(z)\), \(\E[g'^2] = \tfrac12\)

Урок 26 · Оценка по кривой

Mini-batch mean
\(\mu_B = \frac{1}{m}\sum_i x_i\)
Mini-batch variance
\(\sigma_B^2 = \frac{1}{m}\sum_i (x_i - \mu_B)^2\)
Normalize
\(\hat x_i = (x_i - \mu_B) / \sqrt{\sigma_B^2 + \epsilon}\)
Scale and shift
\(y_i = \gamma\,\hat x_i + \beta\)
Running average
\(\mu_{\mathrm{run}} \leftarrow (1 - \alpha)\,\mu_{\mathrm{run}} + \alpha\,\mu_B\)
Inference
\(y = \gamma\,(x - \mu_{\mathrm{run}}) / \sqrt{\sigma^2_{\mathrm{run}} + \epsilon} + \beta\)
Порядок в слое
Fully Connected → Batch Norm → ReLU
Параметры
4 на нейрон: 2 trainable + 2 non-trainable
Has shown to
improve gradient flow; allow higher learning rates; reduce dependence on weights initialization; act as regularization

Урок 27 · Ложка супа и тяжёлый шар

Empirical risk
\(E(w) = \frac{1}{N}\sum_{n} E(x_n, w)\)
Batch
\(\pd{E}{w} = \frac{1}{N}\sum_{n} \pd{E(x_n, w)}{w}\)
SGD
\(\pd{E}{w} \approx \pd{E(x_n, w)}{w}\)
Mini-batch
\(\pd{E}{w} \approx \frac{1}{M}\sum_{n \in MB} \pd{E(x_n, w)}{w}\)
Iterations per epoch
\(\lceil N / M \rceil\)
Шум оценки градиента
\(\sigma / \sqrt{M}\)
Step decay
\(\eta_t = \eta_0 \cdot \mathrm{drop}^{\lfloor t/s \rfloor}\)
Exponential decay
\(\eta_t = \eta_0\,e^{-\lambda t}\)
1/t decay
\(\eta_t = \eta_0 / (1 + \lambda t)\)
Cosine annealing
\(\eta_t = \frac{\eta_0}{2}\bigl(1 + \cos\frac{\pi t}{T}\bigr)\)
Warm-up
\(\eta_t \cdot t / T_w\) при \(t \lt T_w\)
Momentum, слайд 38
\(w^{k+1} = w^k - \eta\,\pd{E}{w}\big|_{w^k}\) \({} - \alpha\,\pd{E}{w}\big|_{w^{k-1}}\)
Momentum, конспект
\(v_k = \alpha v_{k-1} - \eta \nabla E(w_k)\), затем \(w_{k+1} = w_k + v_k\)
Предельная скорость
\(\eta\,\abs{g} / (1 - \alpha)\)
Nesterov, слайд 39 лекции 3
\(w^{k+\frac{1}{2}} = w^k - \alpha\,\pd{E}{w}\big|_{w^{k-1}}\), затем \(w^{k+1} = w^k - \eta\,\pd{E}{w}\big|_{w^{k+\frac{1}{2}}}\); по смыслу поправка прибавляется к \(w^{k+\frac{1}{2}}\)
Nesterov через скорость
\(v_k = \alpha v_{k-1} - \eta \nabla E(w_k + \alpha v_{k-1})\), затем \(w_{k+1} = w_k + v_k\)
Rprop
\(w \leftarrow w - \Delta \cdot \sign(g)\); свой \(\Delta\) у каждого веса растёт при том же знаке и падает при смене
AdaGrad
\(G_k = G_{k-1} + g_k^2\), затем \(w_{k+1} = w_k - \eta\,g_k / (\sqrt{G_k} + \varepsilon)\)
RMSprop
\(s_k = \rho s_{k-1} + (1 - \rho) g_k^2\), затем \(w_{k+1} = w_k - \eta\,g_k / \sqrt{s_k + \varepsilon}\)
Adam: моменты
\(m_k = \beta_1 m_{k-1} + (1 - \beta_1) g_k\), \(v_k = \beta_2 v_{k-1} + (1 - \beta_2) g_k^2\)
Adam: поправка
\(\hat m_k = m_k / (1 - \beta_1^{\,k})\), \(\hat v_k = v_k / (1 - \beta_2^{\,k})\)
Adam: шаг
\(w_{k+1} = w_k - \eta\,\hat m_k / (\sqrt{\hat v_k} + \varepsilon)\)
Обычные значения
\(\alpha = 0.9\), \(\rho = 0.9\), \(\beta_1 = 0.9\), \(\beta_2 = 0.999\), \(\varepsilon = 10^{-8}\)
